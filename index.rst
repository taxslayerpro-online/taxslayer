What Is TaxSlayer Pro?
----------------------------------------------------

**TaxSlayer Pro** is a professional tax preparation software platform used by
licensed tax preparers, accountants, and tax offices across the United States.

It provides tools for:

- Federal and state tax return preparation  
- Secure e-filing  
- Client management  
- Business and firm-level account administration  
- IRS-compliant data security  

----------------------------------------------------
Understanding the TaxSlayerPro My Account Dashboard
----------------------------------------------------

After successfully logging in, users can access the **TaxSlayer Pro Account Hub**.
This dashboard allows professionals to manage both personal and business-level
settings from a single interface.

Key features include:

- Updating firm contact information  
- Managing EFIN and preparer credentials  
- Viewing subscription and product details  
- Accessing support and training resources

Trouble Logging In?
----------------------------------------------------

If you experience issues accessing your **TaxSlayerPro login**, consider the
following steps:

1. Ensure your username and password are entered correctly  
2. Check that Caps Lock is turned off  
3. Clear your browser cache and cookies  
4. Try using a different browser or device  

You may also use the account recovery tools provided on the official login page.

.. raw:: html

    <a href="https://id-vita.taxslayerpro.com/identity/Account/ForgotPassword"
       class="btn-secondary"
       target="_blank">
       Forgot Password
    </a>

Security & Account Protection
----------------------------------------------------

TaxSlayer Pro uses industry-standard security measures to protect user data,
including:

- Encrypted connections  
- Secure login authentication  
- Role-based account access  
- Compliance with IRS security guidelines  

Always log out after accessing your account on shared or public devices.
